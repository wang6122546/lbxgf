## 2026-10-16，第1项：准入培训证照改为非必填

路径：企业履历管理 → 相关方履历 → 人员管理 → 相关方所有人员 → 新增。

- 仅在“人员信息”的“相关方所有人员”范围下显示新增按钮，按钮标黄。
- 新增人员信息使用648px右侧抽屉，沿用已采集原系统表单的字段顺序。
- “准入培训合格证/上岗证”整行标黄，并显示“评审改动：已取消必填，可不上传”。
- 该字段没有红色星号、required属性或阻断保存的必填校验。上传能力保留。
- 其他必填字段保留必填标记和校验。
- 新增人员保存到统一people数据源，列表、统计与刷新状态一致。附件当前仅保存演示文件名及元数据，不上传到原系统。

影响文件：modules/people.js、modules/staff-form.js、styles/enterprise.css。

验证：tests/admission-review.cjs 已通过入口可见性、高亮标记、必填属性、无需准入证照保存成功、列表及统计更新、刷新保留和页面错误检查。
